# Ping Pong Score Keeper

A responsive, interactive scorekeeping widget built with **Vanilla JavaScript** and **Bulma CSS**.

## Features
- **Dynamic Scoring:** Set a custom winning score (Play to 3, 5, 11, etc.).
- **Game Over Logic:** Locks buttons and highlights the winner (Green) and loser (Red) automatically.
- **Responsive UI:** Clean Card interface that works on Mobile and Desktop.

## Tech Stack
- **HTML5** (Semantic Structure)
- **Bulma** (CSS Framework)
- **JavaScript** (DOM Manipulation & State Management)
